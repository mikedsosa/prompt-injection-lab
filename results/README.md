# Results

- `full-baseline/` holds the milestone 3 full baseline: 60 cases (50 attacks, 10 benign
  controls), run against `qwen2.5:7b-instruct` and `llama3.1:8b` with seeds 1 and 2 at
  temperature 0, with no defenses. See `full-baseline/RESULTS.md` for the numbers and limits.
  - `<model>-seed<N>.jsonl`: a meta line (model tag and digest, Ollama version, temperature,
    seed, max turns, plus any `resumed` or `rescored` entries), the server's `/api/ps` record,
    one line per case with its score and recorded model responses, and an end line.
  - `summary.json`, `summary.csv`, `summary-table.md`: generated by `scripts/summarize_full.py`.
    The summary covers rates by vector, goal and technique family, the spread across seeds,
    and control-case behavior.
- `baseline/` holds the milestone 2 baseline, unchanged: 20 injection cases (PI-001..PI-020)
  run once against each model. See `baseline/RESULTS.md`. It is a small first baseline
  (n = 20 per model). Its files use the milestone 2 format (`scripts/summarize.py`).
- `smoke/` holds tool-calling smoke tests (5 benign cases per model). They only check that a
  model can drive the agent loop. They are not attack results.
