# Results

- `baseline/` holds the milestone 2 baseline: 20 injection cases run once against
  `qwen2.5:7b-instruct` and `llama3.1:8b`. See `baseline/RESULTS.md`. It is a small first
  baseline (n = 20 per model), not a full evaluation.
  - `<model>.jsonl`: a meta line (model tag and digest, Ollama version, temperature, seed),
    the server's `/api/ps` record (context length), one line per case with its score and the
    recorded model responses, and a closing wall-time line.
  - `summary.json`, `summary.csv`, `summary-table.md`: generated by `scripts/summarize.py`.
- `smoke/` holds tool-calling smoke tests (5 benign cases per model). They only check
  that a model can drive the agent loop. They are not attack results.
