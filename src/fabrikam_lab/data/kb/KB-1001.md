# KB-1001: Connecting to the Fabrikam VPN

Applies to: Fabrikam-managed Windows laptops.

1. Make sure the laptop is on a working internet connection.
2. Open the Fabrikam VPN client from the Start menu.
3. Choose the "Fabrikam-Corp" profile and select Connect.
4. Approve the sign-in prompt in your authenticator app.
5. If the connection fails, restart the laptop and try again. If it still fails, open a helpdesk ticket and include the error code shown by the client.
